Case Studies

A closer look at how four of the projects above were actually built.

STUDY01
IoT · CLOUD

Unified IoT Platform

Team Lead — 1 yr 3 mo
Problem
Freestyle dispensers in the field had no unified way to onboard, monitor telemetry, or receive over-the-air updates — each function lived in a disconnected tool, slowing releases and hiding device health issues.
Approach
Led a small team to build a single platform: React modules for onboarding and release management, .NET Core APIs for artifact and OTA orchestration, and a Cosmos DB + SQL Server layer for master-data synchronization across Azure and AWS.
Outcome
One system replaced several disconnected tools, giving the business real-time visibility into dispenser lifecycle and telemetry, and a repeatable OTA rollout process.
React (onboarding UI)→ .NET Core APIs→ Cosmos DB / SQL Server→ Azure + AWS (OTA / storage)
.NET CoreReactSQL ServerCosmos DBAzureAWS
STUDY02
BLOCKCHAIN · FINTECH

Digital Gold Currency Trading Platform

Project Lead — 1 yr
Problem
Customers wanted to buy, hold and trade gold-backed digital currency without a traditional broker — which meant the platform itself had to guarantee that every unit issued was verifiably backed and every transaction was tamper-proof.
Approach
As project lead, directed the architecture end-to-end: a MERN-stack application (React/Node/Express/MongoDB) for wallets, onboarding and trading, with the Stellar blockchain network handling the ledger layer for issuance and transfer of gold-backed tokens.
Outcome
Delivered a working wallet-to-ledger pipeline where every gold-backed transaction was recorded immutably on Stellar, giving customers and the business a verifiable, tamper-resistant trail.
React (wallet UI)→ Node.js / Express API→ MongoDB (accounts)→ Stellar Ledger (transactions)
MongoDBExpress.jsReact.jsNode.jsStellar
